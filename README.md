## About me
Front-end developer focused on the React ecosystem. I take a design and a feature brief and turn them into a clear interface: semantic HTML, structured CSS, reusable components and predictable state.

I work comfortably in agile teams — small squads and larger product groups. Typical work: clarify the task, match Figma (spacing, type, breakpoints), split the UI into components, wire data with Redux / Redux Toolkit, then ship a page that holds up on real devices. I prefer simple solutions over clever ones, and I care about code that stays readable after the first merge.

I use **TypeScript** where types actually help (forms, API payloads, shared components), and plain JavaScript when the file does not need more ceremony. Styling with CSS, SCSS, LESS or Tailwind, depending on what the project already uses. Builds with **Vite** or **Webpack**. Git as a daily habit: feature branches, pull requests, reviews on GitHub, GitLab or Bitbucket.

## What I do
* Implement responsive layouts from Figma and Photoshop — pixel-accurate, not “close enough”.
* Build React pages and components with hooks; keep shared state in Redux Toolkit when the UI has real data flow (cart, filters, auth-related screens).
* Structure CSS so it does not collapse at the next breakpoint: mobile-first, reusable classes or SCSS modules, Tailwind when the project is already on it.
* Integrate REST-style data into the UI, handle loading and empty states, and keep forms and lists predictable.
* Take a feature from a ticket to a reviewable PR: small commits, clear names, no leftover console noise.
